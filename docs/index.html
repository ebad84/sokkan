Sokkan PaaS

سکان یک پلتفرم سبک PaaS و CI/CD خودمیزبان است که پروژه‌های گیتهاب، دیتابیس‌ها و SSL خودکار Caddy را با کمترین مصرف رم روی VPS شما مدیریت می‌کند.

تنظیم خودکار روی VPS + میرورهای ایرانی داکر

هر آنچه از یک PaaS سبک نیاز دارید

بدون پیچیدگی‌های اضافه و بدون مصرف نیمی از رم سرور؛ فقط ابزارهای ضروری برای استقرار، پایش و نگهداری سرویس‌های واقعی.

۰۱. دیپلوی خودکار از گیتهاب

تشخیص هوشمند مخزن، Webhook و استریم زنده لاگ

کافی است لینک ریپوی Public یا Private را وارد کنید تا سکان به‌طور خودکار Dockerfile یا docker-compose.yml، پورت EXPOSE و کلیدهای .env.example را شناسایی کند. با GitHub Webhook (امضای HMAC-SHA256) یا Polling دوره‌ای هر پوش جدید به‌صورت خودکار بیلد و روی شبکه داخلی web جایگزین می‌شود.

استریم زنده SSE · ورود یکجای .env · رمزنگاری AES-256-GCM · بدون تداخل پورت Host
۰۲. مدیریت زنده Caddy و SSL

کنترل مستقیم Caddyfile با Rollback آنی

برخلاف ابزارهایی که کنترل پروکسی را از شما می‌گیرند، سکان ویرایشگر کامل Caddyfile را در اختیارتان می‌گذارد. هر تغییر پیش از اعمال با caddy validate بررسی شده، بدون قطعی Reload می‌شود و در تاریخچه نسخه‌ها ذخیره می‌ماند.

گواهی SSL خودکار · جلوگیری از دامنه تکراری · بازگشت تک‌کلیکه
۰۳. مدیریت Docker و دیسک

جایگزین سبک Portainer + پاک‌سازی ایمن

مشاهده لیست کانتینرهای سرور، آمار لحظه‌ای مصرف CPU و رم، خواندن لاگ‌ها و کنترل Start/Stop/Restart/Remove مستقیم از داشبورد. به‌علاوه نمایش تفکیکی فضای دیسک داکر و پاک‌سازی یک‌کلیکه ایمیج‌ها و کش بیلد بلااستفاده.

اتصال مستقیم به docker.sock · docker system df · ایمن برای Volumeها
۰۴. بومی برای VPS ایران و امنیت دولایه

نصب بدون گیر کردن در تحریم + محافظت دولایه

اسکریپت نصب کاملاً انگلیسی bootstrap-vps.sh داکر را مستقیم از مخزن اوبونتو نصب کرده، میرورهای docker.arvancloud.ir و registry.docker.ir را پیکربندی می‌کند و فایروال UFW و Swap را آماده می‌سازد. پنل با دو لایه امنیت (Caddy Basic Auth + کوکی HttpOnly سی‌روزه) محافظت می‌شود.

بدون وابستگی به Alpine APK · نشست پایدار ۳۰ روزه · بکاپ و بازیابی JSON
۰۵. نصب یک‌کلیکه سرویس‌های آماده و دیتابیس‌ها

کاتالوگ آماده با تولید خودکار رمز عبور و رشته اتصال

مصرف منابع و مقایسه با Portainer و Coolify

نصب سریع و ابزار خط فرمان سکان

اسکریپت نصب کاملاً انگلیسی است و روی Ubuntu / Debian به‌طور خودکار داکر، میرورهای ایرانی، فایروال، Swap، Caddy و دستور سراسری sokkan را آماده می‌کند.

۱. نصب صفر تا صد روی VPS جدید 
sudo apt-get update && sudo apt-get install -y git
sudo git clone https://github.com/ebad84/sokkan.git /opt/sokkan
cd /opt/sokkan
chmod +x bootstrap-vps.sh
sudo bash bootstrap-vps.sh

                sokkan update
                دریافت آخرین نسخه از گیت و بیلد مجدد پنل

                مشاهده لاگ زنده پنل یا کانتینر Caddy
              

              

                sokkan reload-caddy
                اعتبارسنجی و Reload بدون قطعی Caddyfile
              

              

                sokkan prune
                پاک‌سازی ایمن ایمیج‌ها و کش بیلد قدیمی
              

              

                sokkan backup
                تهیه آرشیو فشرده از data/، caddy/ و .env
              

              

                sokkan hash-password
                ساخت هش bcrypt برای Basic Auth در Caddy
              

              

                sokkan doctor
                عیب‌یابی سلامت داکر، شبکه web، Swap و Caddy
